# Get Busi Glossary

| Term | Meaning in this project |
|---|---|
| Get Busi | Proposed brand for existing small businesses. |
| Get Busi Start Up | Proposed brand for aspiring founders; the master brief also writes “Busi Start Up”. |
| MVP | Minimum viable product: the smallest safe product that tests a specific customer problem. |
| Concierge pilot | Early service where software and founder support are combined behind the scenes to learn before full automation. |
| MTD | Making Tax Digital. A set of UK digital tax reporting requirements; the applicable service and obligations depend on the taxpayer and income. |
| MTD ITSA | Making Tax Digital for Income Tax Self Assessment; rolling out from April 2026 according to qualifying income thresholds. |
| API | A software interface that lets one product exchange information with another. |
| Multi-tenant | One software service used by multiple businesses while keeping each business's data isolated. |
| Human review | A person checks a draft before an important financial, legal, public, or irreversible action. |
| Source of truth | The one agreed place where the current approved project information lives. |
| SUL | n8n Sustainable Use License; its permitted uses depend on the way the platform is used and exposed to customers. Confirm Get Busi's exact case with n8n. |
| DPIA | Data protection impact assessment: a structured review of privacy risks and safeguards. |
| PECR | UK Privacy and Electronic Communications Regulations, including rules relevant to electronic marketing and some calls. |
| Service message | A factual, non-promotional message about an existing service relationship. Adding promotion can make it direct marketing. |
